## 📋 Описание проекта
>[!info] 
>- Проект представляет из себя простейший **API-калькулятор**, написанный на `Python`, с фреймворком `Flask` для веб запросов и requests для обращения к внешнему API
>- Внешний API нужен для конвертации валют, чтобы всегда были актуальные данные. ⚠️ **Важно:** Конвертер валют требует интернет-соединения для получения актуальных курсов.

---
### Функциональность

| Раздел | Возможности |
|--------|-------------|
| 🧮 **Калькулятор** | Базовые операции (+, −, ×, ÷), степень, тригонометрия (sin, cos, tan, ctg), факториал |
| 🏷️ **Скидки** | Расчёт итоговой цены с учётом процента скидки |
| 💱 **Валюты** | Конвертация валют по актуальным курсам (внешний API Frankfurter) |

## 🚀 Запуск через Docker (рекомендуется)

>[! info]  Сборка Docker-образа 
>```bash
>docker build -t my-calculator .
>``` 

>[! info] Запускаем контейнер на основе созданного образа:
>```bash
>docker run -d -p 8080:8080 --name calc-run my-calculator
>```
>Перейдите по адресу: **http://localhost:8080**

>[! info]  Остановить текущий контейнер:
>```bash
>docker stop calc-run
>```

>[! info] Удалить его из памяти:
>```bash
docker rm -f calc-run
>```
